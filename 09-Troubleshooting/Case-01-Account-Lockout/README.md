\# Case 01. Блокировка учётной записи пользователя



\## Ситуация



Пользователь \*\*User3 (Виктор Дроздов, отдел HR)\*\* не может войти в систему. При вводе правильного пароля Windows выдаёт: \*\*«Учётная запись пользователя заблокирована и не может быть использована для входа в сеть»\*\*.



\- \*\*Тип проблемы:\*\* Account Lockout

\- \*\*Клиент:\*\* User3 (HR)

\- \*\*Компьютер клиента:\*\* DESKTOP-UJAHLGC

\- \*\*Дата обращения:\*\* 28.09.2026



\## Диагностика



\### 1. Подтверждение блокировки



Проверил статус учётной записи в AD:



```powershell

Get-ADUser User3 -Properties LockedOut | Select Name, LockedOut

```



Результат: `LockedOut: True` — учётка действительно заблокирована.



\### 2. Поиск источника блокировки



Открыл \*\*Event Viewer\*\* на контроллере домена → \*\*Журналы Windows\*\* → \*\*Безопасность\*\* → фильтр по \*\*Event ID 4740\*\* («Учётная запись заблокирована»).



В найденном событии:

\- \*\*Заблокированная учётная запись:\*\* `LAB\\user3`

\- \*\*Имя вызывающего компьютера:\*\* `DESKTOP-UJAHLGC`

\- \*\*Компьютер-источник события:\*\* `WIN-SKIC7TCTV5T.lab.local` (контроллер домена)



\*\*Вывод:\*\* попытки входа шли с компьютера самого пользователя. Это не внешняя атака, а сам пользователь несколько раз ввёл неправильный пароль.



\### 3. Конфликт настроек



При попытке выставить флаг «Сменить пароль при следующем входе» через ADUC — галочка оказалась неактивна.



\*\*Причины:\*\*

1\. \*\*Минимальный срок действия пароля\*\* = 1 день — не даёт менять пароль чаще, чем раз в сутки.

2\. \*\*PasswordNeverExpires = True\*\* — флаг «Срок действия пароля не ограничен» \*\*взаимоисключающий\*\* с требованием смены при входе.



\## Решение



\### 1. Сброс пароля на временный



```powershell

Set-ADAccountPassword -Identity User3 `

&#x20;   -NewPassword (ConvertTo-SecureString "Temp@12345" -AsPlainText -Force) `

&#x20;   -Reset

```



\### 2. Снятие флага «пароль не истекает»



```powershell

Set-ADUser -Identity User3 -PasswordNeverExpires $false

```



\### 3. Установка требования смены пароля при входе



```powershell

Set-ADUser -Identity User3 -ChangePasswordAtLogon $true

```



\### 4. Разблокировка учётной записи



```powershell

Unlock-ADAccount -Identity User3

```



\### 5. Проверка результата



```powershell

Get-ADUser User3 -Properties pwdLastSet, LockedOut, PasswordNeverExpires |

&#x20;   Select Name, LockedOut, pwdLastSet, PasswordNeverExpires

```



Результат:

\- `LockedOut: False` — учётка разблокирована

\- `pwdLastSet: 0` — при следующем входе потребуется смена пароля

\- `PasswordNeverExpires: False` — флаг снят



\### 6. Подтверждение с клиента



На клиенте:

1\. Вход под `LAB\\User3` с временным паролем `Temp@12345`.

2\. Windows запросила смену пароля.

3\. Пользователь ввёл новый постоянный пароль.

4\. Вход выполнен успешно.



\## Ключевые выводы



\### Для специалиста L1



\- \*\*Event ID 4740\*\* — основной инструмент диагностики блокировок. Позволяет найти \*\*источник\*\* попыток входа.

\- \*\*Имя вызывающего компьютера\*\* — критично: если это компьютер клиента — виноват сам пользователь; если неизвестное устройство — эскалация в безопасность.

\- \*\*GUI не всегда работает\*\* — при конфликте политик галочка в ADUC не ставится. PowerShell обходит это ограничение.

\- \*\*`PasswordNeverExpires` и «сменить при входе» — взаимоисключающие\*\* флаги.



\### Для пользователя



\- При сбросе пароля используется \*\*временный пароль\*\* с обязательной сменой при входе — это безопасная практика.

\- Специалист L1 \*\*не знает постоянный пароль\*\* клиента — клиент задаёт его сам.
