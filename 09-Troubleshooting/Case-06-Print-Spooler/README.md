# Case 06. Принтеры не видны — остановлена служба Print Spooler

## Ситуация

Пользователь сообщает: **принтеры пропали** из системы / отображаются как «**Нет подключения**». Печать **невозможна** — в диалоге печати **нет ни одного принтера**.

- **Тип проблемы:** Printing / Service
- **Устройство:** Epson L3250 (сетевой, Wi-Fi)
- **ОС:** Windows 11
- **Среда:** Домашний ПК

## Диагностика

### 1. Симптом

В **Параметры → Bluetooth и устройства → Принтеры и сканеры**:

- `EPSON L3250 Series` — **Нет подключения**
- `L3250 Series (Сеть)` — **Нет подключения**

В **диалоге печати** (Ctrl+P) — принтеров **вообще нет**.

### 2. Проверка службы Print Spooler

```cmd
services.msc
```

Найдена служба **«Диспетчер печати» (Print Spooler)**.

**Состояние:** ⚠️ **Остановлена**
**Тип запуска:** Автоматически

### 3. Причина

**Print Spooler (Диспетчер печати)** — служба Windows, которая:

- Управляет **очередью печати**.
- **Обнаруживает** принтеры в системе.
- **Взаимодействует** с драйверами принтеров.

**Если служба остановлена** — Windows **не видит** ни один принтер. Они либо исчезают из списка, либо отображаются как «Нет подключения».

**Это не поломка принтера** — это **остановленная служба Windows**.

## Решение

### 1. Запуск службы

1. `services.msc` → найти **Print Spooler** (Диспетчер печати).
2. **ПКМ** → **Запустить**.
3. Проверить, что **Состояние = Выполняется**, а **Тип запуска = Автоматически**.

### 2. Проверка

После запуска службы принтеры **появились** в списке и стали доступны для печати.

### 3. Тестовая печать

**Параметры → Принтеры и сканеры** → Epson L3250 → **Управление** → **Печать пробной страницы**.

**Результат:** пробная страница **напечатана** ✅.

## Ключевые выводы

### Для специалиста L1

- **Print Spooler — первое, что проверяешь** при проблемах с печатью.
- **Симптомы остановленной службы:**
  - Принтеры «Нет подключения».
  - Принтеры **исчезли** из списка.
  - **Нет принтеров** в диалоге печати.
  - **Задачи висят** в очереди и не уходят.
- **Быстрое решение:** перезапуск Print Spooler решает **80% проблем с печатью**.
- **Если не помогло** — проверять:
  1. **Драйвер** принтера.
  2. **Связь по сети** — `ping <IP принтера>`.
  3. **Очередь печати** — `C:\Windows\System32\spool\PRINTERS` (можно очистить вручную).
  4. **Разрешения** на шару принтера.

### Почему служба может остановиться

- **Ручная остановка** (админ или пользователь).
- **Сбой службы** (из-за драйвера или зависшей задачи).
- **Обновление Windows**.
- **Антивирус**.
- **Некорректное выключение ПК**.

### Как проверить очередь печати

**Через GUI:**
- `control printers` → ПКМ по принтеру → **Просмотр очереди**.

**Через файловую систему:**
- `C:\Windows\System32\spool\PRINTERS` — там **временные файлы** заданий.
- Если служба **остановлена**, а задача **зависла** — файлы остаются.
- **Решение:** остановить службу → удалить файлы → запустить службу.

## Связь с реальной работой

**Эта проблема — классика L1.** На работе ты **будешь сталкиваться** с ней постоянно:

> «У меня не печатает принтер» → **первое действие:** проверить **Print Spooler**.

**Порядок действий L1 при проблеме с печатью:**
1. **Print Spooler** — работает?
2. **Очередь** — есть ли зависшие задачи?
3. **Связь с принтером** — `ping`.
4. **Драйвер** — актуален?
5. **Бумага/тонер** — на месте?
6. **Эскалация** — если не помогло.
