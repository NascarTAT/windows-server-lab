# Knowledge Base (База знаний)

Инструкции для пользователей по типовым проблемам. Написаны простым языком, без технического жаргона — для сотрудников без IT-подготовки.

## Что это

База знаний (KB) — один из ключевых инструментов Service Desk. Она позволяет пользователям **самостоятельно решать** типовые проблемы, что снижает нагрузку на поддержку.

## Публикация на файловом сервере

KB **опубликована** на файловом сервере в виде PDF-файлов — доступна всем доменным пользователям: \\192.168.1.10\KnowledgeBase

**Права доступа:**
- Share Permissions: `Пользователи` — Read
- NTFS Permissions: `Пользователи` — Read & Execute

Пользователи открывают PDF **двойным кликом** — без Markdown-редактора.

## Формат

Каждая статья написана по единой структуре:

1. **Кому** — для кого статья.
2. **Когда использовать** — при каких симптомах.
3. **Симптомы** — что видит пользователь.
4. **Что делать** — пошаговая инструкция.
5. **Результат** — что должно получиться.
6. **Если не помогло** — куда обратиться.
7. **Контакты поддержки**.

## Зачем это в портфолио

- **Показывает навык письма для пользователя** — не для коллеги-админа.
- **Демонстрирует клиентоориентированность** — думаешь о том, как снизить нагрузку на поддержку.
- **Готовый артефакт** — не «прочитал статью», а **создал ресурс**.
