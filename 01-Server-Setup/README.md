# 01. Настройка сервера и статического IP



## 🎯 Что делаем на этом этапе



\- Создаём виртуальную машину для Windows Server 2019.

\- Устанавливаем ОС.

\- Задаём статический IP-адрес 192.168.1.10 с маской 255.255.255.0.

\- Настраиваем DNS на самого себя (127.0.0.1).



## 🧰 Что понадобится



\- VirtualBox

\- ISO-образ Windows Server 2019

\- 2 ГБ ОЗУ минимум для ВМ



## 📝 Шаги



### 1. Создание ВМ в VirtualBox

1\. Открыть VirtualBox → «Создать».

2\. Имя: `Windows Server 2019 Lab`.

3\. Тип: Microsoft Windows, версия: Windows 2019 (64-bit).

4\. ОЗУ: 2048 МБ.

5\. Жёсткий диск: VDI, динамический, 50 ГБ.



### 2. Установка Windows Server 2019

1\. В настройках ВМ → «Носители» → выбрать ISO-образ.

2\. Запустить ВМ, выбрать **Standard (Desktop Experience)**.

3\. Задать пароль администратора.



### 3. Настройка статического IP

1\. Панель управления → Сеть и Интернет → Центр управления сетями.

2\. «Изменение параметров адаптера» → ПКМ по Ethernet → Свойства.

3\. IP версии 4 (TCP/IPv4) → Свойства.

4\. Ввести:

&#x20;  - IP-адрес: `192.168.1.10`

&#x20;  - Маска: `255.255.255.0`

&#x20;  - Основной шлюз: `192.168.1.1`

&#x20;  - DNS: `127.0.0.1` (или `192.168.1.10`)

5\. ОК → ОК.
